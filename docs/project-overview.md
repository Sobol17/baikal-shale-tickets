# Shale Tickets: описание проекта

Shale Tickets - веб-приложение для бронирования билетов на экскурсии. Пользователь выбирает экскурсию, дату и количество взрослых/детских билетов, вводит данные покупателя и сопровождающих, оплачивает бронирование через API Т-Банка и получает на почту организационную информацию.

## Цель продукта

Проект должен закрывать полный цикл продажи билета на экскурсию:

- показать доступные экскурсии и доступные для бронирования даты;
- принять гостевое бронирование без обязательной регистрации;
- инициировать оплату через Т-Банк;
- подтвердить бронирование после успешной оплаты;
- отправить пользователю письмо с деталями участия.

## Основной сценарий v1

В первой версии основным считается гостевое бронирование:

1. Пользователь открывает каталог или страницу экскурсии.
2. Выбирает дату в разрешенном диапазоне и количество взрослых/детских билетов.
3. Указывает email и телефон покупателя, а также имена и фамилии сопровождающих.
4. Приложение создает бронирование в статусе ожидания оплаты.
5. Пользователь переходит на оплату через Т-Банк.
6. После успешной оплаты приложение подтверждает бронирование.
7. Пользователь получает email с организационной информацией.

Личный кабинет, аккаунты клиентов, история бронирований и возвраты платежей не входят в первый архитектурный фокус. Их можно добавить позже без изменения базовой модели бронирования.

## Основные домены

- Экскурсии: описание, маршрут, сезонная категория, длительность, правила участия, взрослая/детская цена и диапазон дат бронирования.
- Бронирования: контактные данные покупателя, дата экскурсии, количество взрослых/детских билетов, сопровождающие, статусы, связь с выбранной экскурсией.
- Платежи: платежные намерения, статусы оплаты, callbacks/webhooks от Т-Банка.
- Уведомления: email с подтверждением и организационной информацией.

## Границы первой версии

В первую очередь проект должен быть надежным в критическом пути: создать бронирование, принять оплату, зафиксировать заказ и отправить письмо. Административные инструменты, промокоды, возвраты, сложные отчеты и личный кабинет рассматриваются как будущие расширения.
